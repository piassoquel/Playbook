# Product Detail 2.0

1. Hero Image
2. Brand + Model
3. Product badges

   - Terrain

5. Who is this for?

Related Products uses RelatedProductIDs.

Badges are driven by:
- NewThisSeason
- StoreFavorite
- Featured
